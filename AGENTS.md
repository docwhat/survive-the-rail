# Project Instructions

- All code must follow the 5 SOLID principles of object oriented programming.
- After your code works, refactor for readability.
- Commit after refactoring or when a task is finished.
- You MUST always include static typing. e.g., `var hit_points: float = 12.0`
- DO NOT USE `ClassDB`. Using it is a sign of a design problem.
- Keep responses concise.
