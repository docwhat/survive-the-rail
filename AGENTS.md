# Project Instructions

- All code must follow the 5 SOLID principles of object oriented programming.
- Use Test Driven Development: Red, Green, Refactor.
- You will probably need to manually instrument the game to be able to test and run things.
- Code must be simple, readable, and easy to debug. Do not over-simplify.
- Commit after refactoring or when a task is finished.
- Keep responses concise.
